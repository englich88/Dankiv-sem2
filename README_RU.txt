DISTILL CONTROL — Данков

Это демонстрационный веб-интерфейс с переходами между экранами. Он пока НЕ подключён к ОВЕН ПР200: температуры и параметры на изображениях являются макетом, кнопки не отправляют команды контроллеру.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите index.html и папку img целиком в корень репозитория GitHub.
3. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root).
4. Сохраните настройки и дождитесь публикации.

Открывайте index.html через опубликованный сайт или локальный веб-сервер. Для работы переходов нужен JavaScript.
